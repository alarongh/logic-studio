# Logic Studio

[Открыть сайт](https://alarongh.github.io/logic-studio/) · [Исходный код](https://github.com/alarongh/logic-studio)

Редактор и симулятор цифровых логических схем в браузере. Переработан из пользовательского архива MIREA Logic v1.1.1; логика и совместимость исходных JSON сохранены, оформление и растровые текстуры заменены.

Автор исходной программы: **alaron**.

## Возможности версии 2.0

- Нейтральный интерфейс, светлая и тёмная темы, чёткая векторная графика.
- 42 встроенных типа компонентов: базовая логика, преобразователи, арифметика, память и дисплеи.
- Симуляция 0 / 1 / X / Z. Одновременная выборка тактовых элементов, диагностика конфликтов и нестабильных схем.
- Разрядность до 16 бит, групповое соединение разрядов одним действием, цвет всех ответвлений источника.
- Поворот расположения портов, точки маршрута проводов, изменение цвета, масштаб и автоматическое вписывание.
- Комбинационные и последовательностные подсхемы с независимым состоянием экземпляров, вложенность до 8 уровней. Подсхему можно открыть, изменить и применить изменения к проекту.
- Тактовые регистры, счётчики, сдвиговые регистры, T/D/JK/RS, RAM / ROM.
- Синтез схем из булевых формул, упрощение тождеств и объединение общих подвыражений.
- Таблицы истинности до 12 ручных входов (4096 строк), экспорт CSV / HTML.
- Запись временной диаграммы изменений сигналов и экспорт CSV.
- Импорт JSON-файла, текста JSON и Markdown-отчёта ИИ; проверка структуры, библиотеки и пинов до изменения проекта.
- Undo / redo, выделение области, копирование / вставка, автосохранение в текущем браузере.
- Экспорт JSON и PNG. Работа без аккаунта и сервера вычислений.

## Работа

Откройте сайт. Нажмите компонент в библиотеке, чтобы добавить его. В режиме «Провод» нажмите выход, затем вход. При включённом «Жгут» соединяются все разряды выбранной группы. Клик по свободному полю во время соединения задаёт точку маршрута.

Двойной клик по переключателю меняет 0 / 1. Значение числового входа задаётся в свойствах. Вкладка «Анализ» содержит диагностику, синтез из формул, временную диаграмму и таблицу истинности.

Чтобы создать подсхему, выделите блоки и нажмите «Подсхема из выделения». Её интерфейс формируется из входов без внутреннего драйвера и выходов, свободных или используемых снаружи. Определение добавится в библиотеку. Схема и библиотека сохраняются одним JSON. У экземпляра доступны кнопки «Открыть подсхему» и «К проекту»; удаление исходного портового пина блокирует применение изменений.

Для ИИ используйте [формат, пины и готовый промпт](AI_IMPORT.md). Встроенная кнопка копирует краткий промпт; документация описывает всю библиотеку.

Проекты сохраняются локально. Для переноса в другой браузер или компьютер скачайте JSON. При редактировании подсхемы вернитесь в родительский проект, чтобы сохранить применённые изменения.

## Локальный запуск и разработка

Для обычной работы можно открыть `index.html` напрямую. Для разработки нужен Node.js 20+:

```sh
npm ci
npm run dev
```

Откройте `http://127.0.0.1:4173`.

```sh
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

`dist/` — готовый статический сайт. `.github/workflows/pages.yml` проверяет проект и публикует его через GitHub Pages.

## Структура

- `app.js` — редактор, исходный симулятор, подсхемы, история и экспорт.
- `extended.js` — дополнительная библиотека и вычисления арифметики / памяти.
- `schema.js` — проверка и нормализация проектов.
- `synthesis.js` — парсер булевых формул и генератор схем, без `eval`.
- `symbols.js` — векторные обозначения блоков.
- `tests/` — проверки логики, форматов и браузерных сценариев.
- `examples/` — четыре исходных примера и дополнительные проекты.

## Границы версии

Это рабочая браузерная версия с расширенной библиотекой; полный паритет со всеми функциями Logisim пока не заявляется. [Проверенная матрица и дальнейшие задачи](FEATURES.md) отделяют доступные функции от запланированных. В частности, файлы `.circ`, HDL / FPGA и библиотека TTL пока не поддерживаются.
