# Функциональность и ориентир Logisim

Ориентир пользователя — практическое построение и симуляция цифровых схем. Официальные справочники: [классический Logisim](https://www.cburch.com/logisim/docs/2.7/en/html/guide/index.html), [Logisim Evolution](https://github.com/logisim-evolution/logisim-evolution).

Версия 2.0 не выдаётся за полную замену всех возможностей обоих приложений.

| Область | Реализовано в Logic Studio 2.0 | Граница |
|---|---|---|
| Редактор | Выделение, перенос, области, история, копирование, масштаб, пины в четырёх направлениях | Поле 3400 × 2300; до 300 блоков / 2000 проводов |
| Провода | Цвет по источнику, режим всех цветов, точки маршрута, групповое соединение разрядов | Жгут состоит из отдельных битовых проводов; собственного многобитного net пока нет |
| Логика | AND, OR, NOT, XOR, NAND, NOR, XNOR, буфер и tri-state | До 16 параллельных разрядов; базовые бинарные вентили с двумя входами |
| Преобразователи | Decoder, encoder, mux / demux | Адрес 1–5 бит; большие mux / demux ограничены 96 отображаемыми пинами |
| Арифметика | HA / FA, сложение, вычитание, умножение, деление с остатком, сравнение, сдвиг | Беззнаковые числа; результаты ограничены шириной шины |
| Память | D / JK / RS / T, тактовый и сдвиговый регистр, счётчик, RAM / ROM | RAM / ROM до 32 слов × 16 бит |
| Подсхемы | Создание, вложение, независимая память экземпляров, редактирование определения | До 24 определений, 32 порта на сторону, 8 уровней, 1000 развёрнутых блоков на определение |
| Анализ | 0 / 1 / X / Z, конфликты, неподключённые входы, нестабильность, таблицы истинности | 12 ручных входов; таблица для памяти — реакция из сохранённого состояния, не временная модель |
| Формулы | Схема из NOT / AND / OR / XOR / NAND / NOR / XNOR; общие узлы и тождества | Полная минимизация Квайна—Мак-Класки / карты Карно пока не реализована |
| Диаграмма | Изменения выходов, временные отметки, CSV | До 12 наблюдаемых выходов, 256 событий; это запись логических событий, без физических задержек |
| Импорт | Старый JSON, новый JSON, вложенный отчёт `circuit`, Markdown с JSON | До 2 МБ; PDF / DOCX отчёты автоматически не разбираются |
| Экспорт | JSON проекта с библиотекой и состоянием, PNG, таблица CSV / HTML, диаграмма CSV | `.circ`, Verilog / VHDL и FPGA не реализованы |
| Дополнительное удобство | Автосохранение, браузер без установки, импорт от ИИ, формулы → схема, темы, управление на мобильных устройствах | Автосохранение относится к текущему устройству |

## Следующие задачи для полного паритета в построении схем

1. Нативные многобитные соединения и разветвители, туннели и именованные сети, масштабируемая область.
2. Импорт / экспорт `.circ` и тестовых векторов; сопоставление моделей компонентов с Logisim.
3. Настраиваемое число входов вентилей, знаковая арифметика, priority encoder, больше памяти и элементов ввода / вывода.
4. Полная минимизация функций и обратное получение формул из схемы.
5. Модель задержек и полноценный выбор сигналов для временной диаграммы.
6. HDL, FPGA и TTL — отдельный расширенный этап, если эти возможности нужны пользователю.

## Сохранённая совместимость

Старый тип `register` передавал входы на выходы без хранения. Такое поведение сохранено под названием «Шина передачи (legacy)». Настоящая память — `sync_register`; изменение смысла старого блока сломало бы существующие схемы.
