Как собрать схему

  1. Добавьте компоненты из библиотеки.
  2. Выберите «Провод», нажмите выход одного блока, затем вход другого.
  3. Дважды нажмите переключатель, чтобы изменить 0 / 1.
  4. Откройте «Анализ» для проверки и таблицы истинности.

Импорт из отчёта ИИ

Вставьте JSON схемы или отчёт с одним JSON-блоком. Схема откроется целиком, вместе с цветными соединениями.
