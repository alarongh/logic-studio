# Изменения

## 2.0.0 — 1 октября 2026

- Убран университетский брендинг; новый интерфейс Logic Studio и векторные обозначения.
- Исключены встроенные PNG base64 из JavaScript.
- Сохранён исходный формат примеров, ID пинов и цвет источника.
- Исправлена зависимость фронтов триггеров от порядка вычисления компонентов.
- Добавлены 19 типов: NAND / NOR / XNOR, числовой вход, пробник, tri-state, splitter, арифметика, TFF, настоящие регистры, счётчик, RAM / ROM.
- Восстановлены и расширены подсхемы: сохранение, вложение, независимое состояние, редактирование.
- Добавлены синтез из формул, временная диаграмма, ориентация пинов, маршруты проводов и групповое соединение разрядов.
- Добавлен импорт отчётов с предварительной проверкой. Ошибка не портит текущий проект.
- Исправлены ID новых объектов после импорта, потеря фокуса полей при симуляции, устаревшая таблица после редактирования, сброс маркеров при таблице.
- Автосохранение, документация импорта, тесты, сборка и публикация GitHub Pages.
