# Код схемы Logic Studio

Кнопка **«Код и импорт»** открывает редактор с подсветкой, номерами строк и живым превью. Код применяется к проекту одним действием, которое можно отменить. **«Из текущей схемы»** выполняет обратное преобразование. Можно копировать текст из ответа ИИ без создания файла.

```logic
circuit "Полусумматор"

switch A(on=true) at(100,100)
switch B(on=false) at(100,300)
xor SUM at(400,100)
and CARRY at(400,300)
indicator S at(700,100)
indicator C at(700,300)

A.out -> SUM.a
B.out -> SUM.b
A.out -> CARRY.a
B.out -> CARRY.b
SUM.y -> S.in
CARRY.y -> C.in
```

Одна команда на строку; также можно разделять команды точкой с запятой. `//` начинает комментарий. Значения строк заключаются в двойные кавычки. JavaScript не выполняется.

- `circuit "Название"` — название проекта.
- `description "Описание"` — описание схемы.
- `тип ИМЯ(параметры) at(x,y)` — компонент. Координаты необязательны: без них блоки размещаются по порядку. Параметры тоже необязательны.
- `ИМЯ.выход -> ДРУГОЕ.вход` — соединение. Блоки можно объявить после соединений.
- `text T1 "Подпись" at(100,60)` — текст на поле.

Параметры: `width=4` (разрядность), `address=3` (адресные биты), `on=true`, `value=9`, `label="A"`, `orientation="south"`, `mode="hex"`, `direction="right"`, `memory=[1,2,3,4]`. Числовой ввод использует `input`, а показание шины — `probe`.

```logic
circuit "Числовой вход"
input DATA(width=4, value=9) at(100,100)
probe RESULT(width=4) at(500,100)
DATA.out0 -> RESULT.in0
DATA.out1 -> RESULT.in1
DATA.out2 -> RESULT.in2
DATA.out3 -> RESULT.in3
```

Все типы и имена пинов перечислены в [AI_IMPORT.md](AI_IMPORT.md). Для восстановления разрезанного провода соедините выход одного `contact` с входом другого: `CUT1.out -> CUT2.in`.

Обратное преобразование сохраняет координаты, цвета, точки маршрута, подписи, параметры и состояние. Для точного переноса библиотек подсхем используется команда `library` с JSON-определением; редактор создаёт её автоматически. Дополнительные данные провода можно записать после соединения:

```logic
A.out -> SUM.a {"id":"w1","color":"#247a70","bends":[{"x":300,"y":120}]}
```

Импорт поддерживает `.logic`, `.txt`, старый JSON, а также Markdown-ответ с одним блоком `logic` или `json`. Неверные типы, пины и ссылки блокируют применение, текущий проект сохраняется. Лимиты проекта остаются прежними: 300 блоков, 2000 проводов, текст до 2 МБ.

`Tab` вставляет два пробела, `Ctrl Enter` применяет код, `Ctrl S` скачивает его. Обычное колесо над редактором кода прокручивает текст; над полем схемы оно изменяет масштаб вокруг курсора.
